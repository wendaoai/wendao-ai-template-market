# 一篇用于模板审查的公众号文章

这段开场用于检查正文颜色、字号、行距和段落间距。模板应该让内容更清晰，而不是抢走内容本身的注意力。

## 为什么需要稳定的排版系统

公众号文章通常同时包含观点、步骤、引用、图片、表格和代码。统一渲染器可以保证模板更新只改变受控参数。

> 好模板不是装饰越多越好，而是让读者更快看到结构和重点。

### 操作步骤

1. 先确认文章结构。
2. 再选择适合内容类型的模板。
3. 预览当前文章效果。
4. 确认后应用到本文。

| 检查项 | 目标 |
| --- | --- |
| 标题 | 层级清楚 |
| 引用 | 与正文有区别 |
| 列表 | 连续阅读不拥挤 |
| 代码 | 对比度足够 |
